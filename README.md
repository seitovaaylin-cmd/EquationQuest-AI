# EquationQuest AI

## Project Overview
EquationQuest AI is an interactive web-based mathematics learning application focused on linear equations. It supports differentiated learning through three levels of difficulty.

## Learning Levels
- Foundation: One-step equations with guided hints.
- Standard: Two-step equations with independent problem-solving.
- Advanced: Multi-step equations and real-world applications.

## Features
- Responsive HTML, CSS and JavaScript interface
- Dynamically generated linear equations
- Instant answer checking
- Level-specific hints and step-by-step solutions
- Interactive learning activities

## Technology
HTML, CSS and JavaScript.

## AI Integration
The current version uses rule-based problem generation and feedback. Live AI integration is planned but is not yet connected.

## Educational Purpose
To demonstrate differentiated mathematics instruction by adapting task difficulty and instructional support to learners' needs.
